# Checking the OPatch inventory

Commands that list the patches installed in an Oracle home.

```bash
$ $ORACLE_HOME/OPatch/opatch lsinventory

$ $ORACLE_HOME/OPatch/opatch lsinventory|grep "Patch description"
Patch description:  "Database Patch Set Update : 11.2.0.4.4 (19121551)"
```
